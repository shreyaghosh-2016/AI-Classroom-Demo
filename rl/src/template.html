Experiment settings

Movement, rewards & more

Movement is deterministic: the agent follows the selected direction. Walls and borders keep it in place. Every action updates Q immediately when learning is on. Epsilon controls exploration in action selection, not movement noise.

Exit gives the displayed reward and ends the episode.

Changing the living reward keeps learned Q-values; use Reset for a clean comparison. Runs longer than 500 moves are truncated for convenience, keeping the usual bootstrap target.

Auto-play moves and updates Q together at each step. Fast training uses the same update rule.

Inspired by UC Berkeley CS188’s Gridworld and Q-learning teaching demos. Original implementation; not an official Berkeley tool. Works offline. Q-values are learned from sampled transitions, not computed by value iteration.
